# 🌍 WanderWorld Travel Website

A modern and visually appealing travel website developed using **HTML5** and **CSS3** as part of the Frontend Development Industrial Training Program.

## 📖 Project Overview

WanderWorld is a static travel website designed to showcase popular travel destinations and travel packages through a clean and user-friendly interface. The project focuses on proper HTML structure, attractive styling, and responsive layout principles.

## ✨ Features

* Modern navigation bar
* Eye-catching hero section
* Popular destinations showcase
* Travel package listings
* Attractive cards with images
* Clean and organized layout
* Fully built using HTML and CSS

## 🛠️ Technologies Used

* HTML5
* CSS3

## 🎯 Learning Objectives

## 📸 Website Sections

### Home

A visually appealing hero section introducing the travel website.

### Destinations

Highlights popular travel destinations with images and descriptions.

### Packages

Displays travel packages and pricing information.

### Footer

Contains copyright and website information.

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html` or open it in a browser.
